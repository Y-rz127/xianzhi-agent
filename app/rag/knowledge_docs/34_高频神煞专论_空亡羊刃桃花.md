# 高频神煞专论：空亡·羊刃·桃花

> 空亡、羊刃、桃花为八字断事中最常用的三大神煞，出现频率远高于其他神煞。本篇含三大神煞的查法、象义、喜忌、岁运应事、与五行格局配合、常见误区辨析。供各专项 Worker 检索引用。
> 引用典籍（主题标签，非古籍原篇名）：《渊海子平·神煞主题》《三命通会·神煞主题》《神峰通考·神煞主题》。
> **核心原则：神煞仅作辅助取象，先看五行生克格局定吉凶，后参神煞观性情征象；神煞为用为忌取决于全局喜忌，不可单靠神煞断祸福。**

> ⚠️**全局前置约束（核心，AI 须严格遵守）**：
> 1. **神煞服从五行格局**：格局五行大凶，满盘贵人不能免祸；格局五行佳，虽带凶煞不过小疵。神煞不可单独断祸福。
> 2. **神煞喜忌看全局**：同一神煞，为用神则显吉象，为忌神则显凶象。如羊刃为用主权柄刚断，为忌主刚愎血光。
> 3. **空亡不是真空**：空亡主虚浮不实，非"没有"；空亡逢冲合填实则不空，须看岁运引动。
> 4. **桃花不是淫**：桃花主人缘、容貌、感情，有制则为才艺魅力，无制方主感情多变动。
> 5. **羊刃不是必血光**：羊刃主刚猛，为用主权柄武职，为忌方主刚愎血光；须分喜忌。
> 6. **查法存在流派差异**：部分神煞查法有年支/日支两种起法，本卡以日支为主、年支为辅，遇到差异须注明。

## 一、空亡

### 1. 查法
空亡以日柱干支所在旬推算，每旬十干配十二支，多出两支为空亡。

| 日柱所在旬 | 空亡支 |
|-----------|--------|
| 甲子旬（甲子-癸酉） | 戌、亥 |
| 甲戌旬（甲戌-癸未） | 申、酉 |
| 甲申旬（甲申-癸巳） | 午、未 |
| 甲午旬（甲午-癸卯） | 辰、巳 |
| 甲辰旬（甲辰-癸丑） | 寅、卯 |
| 甲寅旬（甲寅-癸亥） | 子、丑 |

**口诀**：甲子旬中戌亥空，甲戌旬中申酉空，甲申旬中午未空，甲午旬中辰巳空，甲辰旬中寅卯空，甲寅旬中子丑空。

> 📌**流派备注**：空亡查法有以日柱为主和以年柱为主两派。本卡以日柱为主，年柱空亡仅作辅助参考。大运流年空亡同理，以大运流年干支所在旬推。

### 2. 核心象义
- **虚浮不实**：空亡之字，力量减弱，主虚、主空、主不实。
- **事难成就**：所空之十神，主该方面事多虚浮、难落实。
- **来去匆匆**：空亡主事物来得快去得快，留不住。
- **悟性超脱**：空亡也主悟性高、思想超脱、对世俗看淡。

### 3. 十神空亡象义
| 空亡十神 | 象义 |
|---------|------|
| 比肩空 | 兄弟朋友缘薄，合伙易散 |
| 劫财空 | 争夺少，但也少助力 |
| 食神空 | 口福减，子女缘薄，才艺难发挥 |
| 伤官空 | 才华难显，女命子女缘薄 |
| 偏财空 | 偏财难聚，父亲缘薄，男命偏缘虚 |
| 正财空 | 正财不稳，妻缘薄，财运虚浮 |
| 七杀空 | 压力减小，女命偏夫缘薄，武职难就 |
| 正官空 | 贵气减，男命子女缘薄，女命夫缘虚 |
| 偏印空 | 继母缘薄，玄学悟性减 |
| 正印空 | 母亲缘薄，学业文书虚浮，贵人助力减 |

### 4. 空亡的几种情况
- **真空**：空亡之支无冲合填实，且月令不生扶，为真空，力量大减。
- **假空（不空）**：
  - 空亡逢冲：冲则动，空被冲实
  - 空亡逢合：合则实，空被合住
  - 空亡之支得月令生扶：旺则不空
  - 空亡之支透干：天干透出则不空
- **岁运填实**：原局空亡，大运流年走到空亡之支，称为填实，该年该运空亡转为实，应事明显。

### 5. 岁运应事
- 大运逢空亡：该十年所主十神方面事多虚浮，难有大成就。
- 流年逢空亡：该年所主十神方面事多变动、来去匆匆。
- 原局空亡逢大运填实：该运空亡转实，应事明显（吉则吉，凶则凶）。
- 原局空亡逢流年填实：该年应事明显。

### 6. 常见误区
- ❌ 空亡=没有：空亡是力量减弱、虚浮不实，不是完全没有。
- ❌ 空亡一定凶：空亡为忌神反吉（忌神空亡则忌神无力），为用神反凶。
- ❌ 空亡永久空：逢冲合填实则不空，岁运可填实。

## 二、羊刃

### 1. 查法
羊刃为帝旺之支，古子平只认阳干有刃，阴干无刃为正统。

| 阳干 | 羊刃支 |
|------|--------|
| 甲 | 卯 |
| 丙、戊 | 午 |
| 庚 | 酉 |
| 壬 | 子 |

> 📌**流派备注**：后世部分流派把阴干帝旺叫"暗刃"（乙刃在寅、丁己刃在巳、辛刃在申、癸刃在亥），属衍生说法，仅作参考，不作正统。本卡以阳干有刃为正统。

### 2. 核心象义
- **刚猛刚烈**：羊刃主性格刚猛、脾气急躁、好胜心强。
- **权柄武职**：羊刃为用主权柄、武职、执行力强。
- **血光灾伤**：羊刃为忌主刚愎自用、易有血光、手术、外伤。
- **帮身夺财**：羊刃为比劫之极，帮身力强，也主夺财、克妻。

### 3. 羊刃喜忌
- **羊刃为用（身弱）**：
  - 性格：刚断有魄力、执行力强
  - 事业：宜武职、执法、外科、竞技等刚猛行业
  - 财运：帮身任财，可担大财
  - 健康：体质强健
- **羊刃为忌（身旺）**：
  - 性格：刚愎自用、脾气暴躁、易冲动
  - 事业：易与人冲突、官非口舌
  - 财运：夺财破财、克妻
  - 健康：易有血光、手术、外伤、高血压

### 4. 羊刃与官杀配合
- **羊刃驾杀**：羊刃+七杀，杀刃两停，为大贵之格，主武职权柄。
  > 《渊海子平》云："杀无刃不显，刃无杀不威。"
- **羊刃逢冲**：羊刃逢冲为"羊刃倒戈"，主血光、灾病、手术。
- **羊刃逢合**：羊刃逢合为"合刃"，刚猛之气被合住，凶性减。
- **羊刃逢刑**：羊刃逢三刑，主刑伤、官非、血光。

### 5. 岁运应事
- 大运逢羊刃（为忌）：该十年易有破财、官非、血光、感情变动。
- 流年逢羊刃（为忌）：该年易有冲动决策、破财、外伤、争执。
- 羊刃逢冲之年：血光、手术、车祸风险高，宜稳守。
- 羊刃逢合之年：刚猛之气被合，宜收敛。

### 6. 常见误区
- ❌ 羊刃一定血光：羊刃为用主权柄刚断，为忌方主血光。
- ❌ 阴干有羊刃：古子平正统只认阳干有刃，阴干无刃。
- ❌ 羊刃驾杀一定贵：须杀刃两停、身杀两停方为贵，杀重刃轻或刃重杀轻皆不成格。

## 三、桃花（咸池）

### 1. 查法
桃花以年支或日支查，申子辰在酉，亥卯未在子，寅午戌在卯，巳酉丑在午。

| 年/日支 | 桃花支 |
|---------|--------|
| 申、子、辰 | 酉 |
| 亥、卯、未 | 子 |
| 寅、午、戌 | 卯 |
| 巳、酉、丑 | 午 |

**口诀**：申子辰鸡叫乱人伦（酉），亥卯未鼠子当头忌（子），寅午戌兔从茅里出（卯），巳酉丑跃马南方走（午）。

> 📌**流派备注**：桃花查法有年支起和日支起两派。本卡以日支为主，年支桃花作辅助。墙外桃花（时柱桃花）与墙内桃花（年月日柱桃花）的区分属民间说法，传统子平不严格区分。

### 2. 核心象义
- **人缘魅力**：桃花主人缘好、有魅力、异性缘佳。
- **容貌才艺**：桃花主容貌姣好、有艺术才华、审美佳。
- **感情多变动**：桃花为忌或无制，主感情多变动、情缘复杂。
- **聪明灵巧**：桃花也主聪明、反应快、善于交际。

### 3. 桃花喜忌
- **桃花为用或有制**：
  - 人缘好、有魅力、异性缘佳
  - 有艺术才华、审美佳
  - 感情虽丰富但能自控
  - 宜演艺、公关、销售、艺术等需人际魅力的行业
- **桃花为忌或无制**：
  - 感情多变动、情缘复杂
  - 易因感情生是非
  - 沉迷情欲、影响事业

### 4. 桃花与五行配合
- **水桃花（子）**：聪明灵动、感情细腻，但易多愁善感。
- **火桃花（午）**：热情奔放、魅力外放，但易急躁冲动。
- **金桃花（酉）**：精致优雅、审美佳，但易挑剔高冷。
- **木桃花（卯）**：温柔浪漫、有艺术气质，但易优柔寡断。

### 5. 桃花与其他神煞配合
- **桃花逢合**：合则私情纠缠，感情易有纠葛。
- **桃花逢冲**：冲则感情变动大，易有突然的感情事件。
- **桃花逢刑**：刑则因感情生是非、官非。
- **桃花逢空亡**：桃花空则人缘减、感情缘薄。
- **桃花+羊刃**："桃花带刃"，易因感情生灾、情杀纠纷。
- **桃花+官杀**：女命桃花官杀混杂，感情复杂。

### 6. 岁运应事
- 大运逢桃花：该十年人缘佳、异性缘旺、感情机会多。
- 流年逢桃花：该年异性缘旺、易有感情事件、社交活跃。
- 桃花逢冲之年：感情变动大，易有分手、新恋情。
- 桃花逢合之年：易有稳定感情、结婚机会。

### 7. 常见误区
- ❌ 桃花=淫：桃花主人缘魅力，有制则为才艺，无制方主感情多变动。
- ❌ 墙外桃花一定出轨：墙内墙外区分属民间说法，传统子平不严格区分，须看全局喜忌。
- ❌ 女命桃花一定不好：桃花为用或有制，主人缘魅力才艺，反为优点。

## 四、三大神煞综合应用

### 1. 神煞叠加效应
- **空亡+桃花**：感情缘薄、来去匆匆、难稳定。
- **空亡+羊刃**：刚猛之气减，但也主虚浮不实的冲动。
- **羊刃+桃花**："桃花带刃"，易因感情生灾，须重点提示。
- **空亡+羊刃+桃花**：三大神煞叠加，感情与冲动交织，须综合五行格局判断。

### 2. 神煞与十神配合
- 神煞落在不同十神上，象义不同：
  - 桃花在正官：女命夫缘有魅力，但也主夫多情。
  - 羊刃在正财：夺财克妻，男命婚姻不稳。
  - 空亡在正印：母亲缘薄、学业虚浮。

### 3. AI 输出规范
- 先论五行格局定吉凶，后参神煞观象义。
- 神煞为用为忌须明确说明，不可单靠神煞断祸福。
- 涉及桃花、羊刃等敏感神煞，用语须中性，避免"淫荡""克妻"等绝对化表述。
- 空亡须说明真空假空、岁运填实情况。
