## 每日黄历功能 — 确认版实施方案

方案经对照项目代码与 lunar-python 1.4.8 包源码逐项验证,整体成立。已确认:所有 lunar API 存在(requirements.lock 已锁 1.4.8,零新增依赖)、免鉴权正确(security.py 中间件只拦 admin 路径)、liuyao 是子应用最佳模板、工具全部为同步 @tool 返回 str、前端仿 LiuYao.vue 且不动 shared/uniapp。

### 实施步骤

1. **领域层** `app/domain/huangli_calc.py`(纯函数,对齐 bazi_engine 下沉做法):
   - `build_huangli_day(date) -> dict`:宜忌/冲煞/彭祖/吉神凶煞/五神方位/值神黄黑道/建星/九星/二十八宿/节日节气/12 时辰条;显式固定 sect 参数(getDayYi(sect=1) 等),getDayNineStar() 调 .toString() 转文本
   - `filter_zeji(yi, start, end, avoid_chong) -> list`:逐日筛宜、吉神(天德/月德/天赦/四相)加星排序、避冲过滤
   - 模块级 `YI_JI_ITEMS` 常量词表(硬编码,不依赖 lunar 私有表),供 zeji 校验与 /items 接口

2. **子应用** `app/sub_app/huangli/`(仿 liuyao:纯函数 + routes 组装):
   - `__init__.py` 一行 docstring;`huangli_app.py` 纯函数
   - `routes.py`:`APIRouter(prefix="/huangli", tags=["HuangLi"])`
     - `GET /api/ai/huangli/day?date=`(省略=今天,1900-2100)
     - `GET /api/ai/huangli/range?start=&end=`(>31 天 400;每天 {date, lunar_day, festivals, jieqi, yi_top5, ji_top3, 天赦标记})
     - `GET /api/ai/huangli/zeji?yi=&start=&end=&avoid_chong=`(>60 天 400;yi 不在词表 400)
     - `GET /api/ai/huangli/items`
   - 错误处理 HTTPException + client_error();不进 AppContext、无鉴权依赖
   - `app/api/routes.py` 加 import + include_router 两行

3. **Agent 工具** `app/tools/huangli.py`:`huangli_today(date="")`、`huangli_zeji(yi, start, end, avoid_chong="")` 两个同步 @tool,Google 风格 docstring,返回 str 文本摘要;导出 `huangli_tools`,`main.py` local_tools 拼接处加一项。不动 agent 核心、不动 prompt(zeji Worker 观察效果后再说)

4. **前端 Web**(本期范围,uniapp 不动、shared 不动):
   - `frontend/src/api/index.ts`:类型 + getHuangLi/getHuangLiRange/getHuangLiZeji/getHuangLiItems(照抄 castLiuYao 的 apiFetch 模式)
   - `frontend/src/views/HuangLi.vue`(仿 LiuYao.vue,glass-card + scoped 专属色,宜忌 chip 用降饱和墨绿/绛红):今日/指定日卡片(日期切换 + 干支 + 节日节气徽标 + 宜忌大字区 + 冲煞/彭祖/值神/建星栏 + 吉神凶煞折叠 + 五神方位)、十二时辰吉凶横条(点击展开时辰宜忌)、择吉面板(事项下拉 + 范围 + 避冲生肖 → 吉日卡片)
   - `frontend/src/router/index.ts` 加 `/huangli`(meta.title「每日黄历」);App.vue 导航加入口(专属色 icon)
   - 月历简版用 range 数据渲染(宜忌首项 + 节日/节气/天赦角标)
   - 页脚复用 Disclaimer 口径:"传统民俗文化参考"

5. **测试** `tests/test_huangli.py`(仿 test_liuyao.py 纯函数断言):3~4 个黄金日期快照(宜忌集合/冲煞/彭祖/值神/建星)、range 超 31 天、zeji 词表校验/避冲过滤/60 天上限

6. **README** 补「每日黄历」一节;冒烟:起服务打三个接口 + 前端点一遍

不碰数据库、不碰 RAG 索引、无迁移。预计一个工作日。
