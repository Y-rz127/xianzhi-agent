- **触发条件**：用户意图 `domain == "theory"`（纯命理理论/术语/古籍问法）→ `_build_messages` 选用 `theory` worker（expertise = 178 字）

## 说明

- **最少**：首次理论提问、无历史摘要、知识库仅命中极少 → 约 1354 字 / 2437 token。
- **典型**：理论问题触发 1~2 条知识库检索（古籍论断数百字）+ 中等历史。
- **上限**：知识库检索打满 2500（3 query 各 850）+ 历史摘要 600 + 最近对话 1542。
- 与 `workflow_chitchat.md` 的关键差异：System 多 178 字理论断法；**知识库检索会真正执行**（上限 2500），而闲聊固定 16 字。
