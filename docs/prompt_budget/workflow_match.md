## 说明

- **最少**：首轮合婚、无摘要/历史/断事参考、对方盘未提供（单盘事实 + 无 match_basis）→ 约 5873 字 / 10571 token。
- **典型**：中等历史 + 双盘事实 + 合婚基础数据 + 1~2 条知识库检索。
- **上限**：历史摘要 600 + 最近对话 ~1400 + 双盘事实 5100 + 合婚基础 900 + 断事参考 1570 + 知识库 2520，理论峰值，几乎不可能同时打满。
- **这是 Workflow 路径单次调用（B）token 最重的场景**——双盘事实 + 合婚基础数据 + 最大 worker 断法。
- 相比 7/29 版本：System 1407→2295 字；双盘事实 1700~2200 → 3400~5100；合婚基础数据 200~1500 → 0~900（按实测校准）；相似命例注入移除；最近对话 6 条→3 条。
- 与 `workflow_regular.md` 关系：本场景 = 常规断事 + （双盘事实替换单盘）+ 合婚基础数据 + 最大 System。若加上调用 A（拆解，~1231~1471 字）与调用 D（Reviewer LLM 深审，双盘时 ~6200~11800 字，见 `workflow_repair.md`），合婚一轮 A+B+D 约 **13500~27400 字 / 24300~49400 token**（仅主路径已含）。
