## 修复：region-data.ts 区县数据系统性补全
- **问题**：用户反馈钦州市只有钦南区/钦北区，缺灵山县/浦北县。根因是初版录入时每个地级市只填了「市辖区（区）」，漏掉所有「县/县级市」（全国 333 市系统性缺失）。
- **数据来源**：用代理从 github raw 拉取权威行政区划 `modood/Administrative-divisions-of-China` 的 `pca-code.json`（省→市→区/县三级，137KB，31 个省级行政区）。沙箱直连超时，走本机代理 `127.0.0.1:7890` 成功（curl 写 /tmp 报 EXIT=23，改写到工作区 `.tmp_fetch/` 才成功）。
- **合并脚本** `.tmp_fetch/merge_region.py`：解析旧 `region-data.ts` 的 345 个城市经度映射 → 以 pca.json 的区县名为准补全 districts → 直辖市(市辖区映射回省名) + 省直辖县级行政区划/县/自治区直辖县级行政区划等 5 个特殊容器**展平**为所属省的直接城市（硬编码 43 个县级市经度，兜底用省首市经度，绝不留 0 经度）→ 重写 `region-data.ts`。
- **结果**：31 省、381 城市、区县全量补全；经度 0 残留 0；`vue-tsc` 零错误。钦州市现在=[钦南区,钦北区,灵山县,浦北县] ✓。
- **注意**：pca.json 仅含 31 个内地省级区，未含香港/澳门/台湾（属中国，但"先不做海外"且数据源无，已向用户说明可作为后续补充）。数据文件在 `uniapp/src/utils/region-data.ts`（utils/ 不被 gitignore；根 data/ 被忽略故不放那）。
